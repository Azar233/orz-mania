# UI 规范

本文件约束后续 UI 修改，目标是保持简洁、统一和可维护。尺寸均为 1280×720 逻辑画布单位；窗口缩放通过现有画布映射完成。

## 控件类别

同类控件保持相同尺寸和字体，不因中文或英文、ON/OFF 或当前选项而改变宽度。不同用途的类别允许使用表中不同尺寸。

| 类别 | 尺寸 | 字号 | 使用位置 |
| --- | --- | --- | --- |
| 设置值按钮 / 输入框 | 112×32 | 16 | 语言、自动演示、VSync、FPS 显示、自定义 FPS |
| 侧栏导航 / 全局操作 | 174×36 | 16 | Esc 菜单侧栏、关闭菜单、退出游戏 |
| 页面操作按钮 | 156×36 | 16 | 按键绑定标题右侧恢复默认、结算返回 / 重试 |
| 曲库导入操作 | 488×46 | 16 | 导入文件夹、导入谱面、刷新 |
| 暂停操作（皮肤例外） | 398×116 | 素材原字形 | Retry / Quit，使用 pause-retry.png / pause-back.png，暂停时只显示这两个操作 |
| 分段选择器 | 高 32 | 14 | FPS 预设、1K–9K；宽度随组内数量等分 |
| 按键绑定键帽 | 高 96，宽度按轨道数计算 | 主键名 18–28 | 保留现有长键名缩小和窄键帽缩写逻辑 |
| 标题栏图标菜单入口 | 44×44命中区、36×36图标 | — | 点击左上品牌图标；保留Esc快捷键 |

## 排版与状态

- 普通按钮用 `menuButton`；设置值用 `settingValueRect` / `settingValueButton`，右边缘统一为 x=980。不要另写语言按钮或开关的专属尺寸。
- 普通Esc菜单仅左右两栏，保留竖向分隔线，不划分右侧底部页脚。左栏底部关闭菜单在y=496、退出游戏在y=540，共用 `menuActionRect`；恢复默认位于按键绑定标题行右侧，使用 `bindingResetRect`，仅重置当前键数。
- 游玩倍速标志与AUTO同为62×55、圆角4；低于1.00×为绿色、高于1.00×为红色，1.00×隐藏。AUTO开启时倍速标志排列在其下方并间隔10；未开启时使用AUTO所在位置。显示缓存的本局倍率与当前语言“倍速/Rate”，不逐帧重建倍率文本。
- AUTO与倍速色块复用 `drawModBadge`，上下两行分别在同一尺寸文字区域按字体度量居中，避免手写横向偏移。
- 主页移除右上Esc按钮，点击左上图标进入菜单。`libraryMenuRect`提供固定44×44命中区；图标围绕原中心平滑放大至108%，移出回落，绘制缩放不改变点击区或标题位置。复用选曲动画时钟与缓动，不创建计时线程；菜单打开、开始游玩或失焦时清除悬停状态。
- 游玩暂停界面的 Retry / Quit 是用户明确指定的皮肤例外，沿用原有图片、字形与透明度反馈，不改成普通菜单按钮，也不因界面语言切换重绘素材文字。绘制与命中区域共用 `pauseActionRect`。
- 结算返回 / 再次挑战按用户要求使用半透明直角底色（RGB 38,32,47，alpha 120），保留156×36尺寸与16号居中文字；两键在右下方并排、间隔16，避开左侧成绩图与FULL RECALL。绘制与点击共用 `resultActionRect`，不改变其他菜单按钮样式。
- 结算达成标识放在右侧评级下方（`resultAchievementRect`），不能覆盖左侧RECENT HIT TIMING。名次/保存状态提示使用 `resultNoticeRect`，与右下操作按钮组同宽、居中，位于达成标识与按钮之间；中英文及长状态文案在区域内适配和裁剪。
- 设置行标签用 `centeredSettingLabel`，与同一行的值控件垂直居中；值文本使用 `centeredText`，按实际字体度量计算位置。不要靠固定偏移猜测文字中心。
- 设置行标签字号 17，按钮 / 输入值字号 16，辅助说明 12–14；页面标题 26。长文案优先精简或调整换行，不能溢出相邻控件。
- 普通控件圆角为 4；底色 RGB(38,32,47)，选中 / 启用底色 RGB(72,42,65)，强调文字使用 `PINK`。不要把普通选项做成整块高亮粉色。
- 分段选择器采用相同选中底色与强调文字。键帽可加细边框表达焦点 / 录入，不能改变尺寸导致排列跳动。
- 页面内边缘、同一列的控件、同组按钮的间隔必须对齐。同一组使用固定步距，不为个别选项添加例外偏移。
- 头部和菜单使用项目品牌图标。游戏皮肤中的音符、判定和成绩图像遵循皮肤布局，不与普通表单按钮混为一类。
- 长条尾帽与条身使用同一圆角几何、颜色和透明度，避免完整圆形尾帽与独立半透明贴图叠加产生接缝。长条头覆盖条身下端；绘制修改不顺带改变尾部判定规则。
- 选曲左栏宽度与338宽的封面对齐，标题和作者不得溢出到右侧歌曲列表。键数与时长同列展示，不覆盖封面。超长标题才启用带两端停留的滚动；宽度只在文字改变时测量，复用已有时钟和字体缓存，不增加逐帧文字重建或独立计时线程。
- 本地成绩榜位于左栏参数下方，宽338，显示四条记录；区域内滚轮只滚动成绩。游玩榜为左上方半透明直角面板，宽度随轨道左边界收缩，显示本次及附近历史记录，不能覆盖轨道或角色。Tab可隐藏，但游戏按键绑定优先。排行榜只在判定结果变化时更新顺序，不逐帧排序或读写文件。
- 曲库抽屉按谱面包所在目录＋歌手＋歌名分组，不能把不同目录的同名曲目合并；同包客串作者不拆分。试听连续性以实际音频路径为准，同音频切难度保持播放，切换谱面包或包内不同音频时切换试听；分组键仅重建曲库时计算。
- 曲库抽屉按歌名字典序排列，忽略英文大小写；同名依次比较歌手、谱师及文件路径，中文按字符序而非拼音，排序键只在重建曲库时生成。搜索栏使用标题栏右侧现有空位（454,22,774,36），不挤占列表视区；支持原生TextInput/IME、空格分隔关键词AND、歌名/歌手/谱师/难度子串匹配。元数据预先小写化，过滤只在规范化查询变化时执行，不逐帧扫描、排序或读盘。输入限制512字节，删除按UTF-8字符边界，空结果不允许启动旧选择，搜索焦点屏蔽游戏/导入快捷键。
- 游玩Tab提示仅开局显示约1.6秒（1秒停留、0.6秒淡出），随后不再绘制；Tab被绑定为游戏按键时不显示提示。
- 游玩右下角不再重复显示键数、播放时间与击打偏移条；保留右上进度圆盘、右侧按键映射与结算页击打偏移统计。
- FPS/帧耗时保持左下角单行，逻辑x=4并使用紧凑分隔间距，减少与左侧立绘重叠。曲库列表使用共用 `libraryListRect` 延伸到y=696，正常可显示6个完整条目及部分下一条；裁剪、命中、滚动下限与可见候选范围均从同一视区推导，继续仅绘制可见条目。
- 偏移校准使用同尺寸独立面板，从设置页进入；模式和开关为112×32、页脚操作156×36，绘制/点击复用Rect。默认目押：采用不带旧音押偏移的中立视觉时钟，校准主判定延迟，并联动视觉补偿保持与该参考一致的下落位置，使目押输入准确命中；音押可选，显式应用时更新主判定延迟。两种模式都显示建议判定偏移，切换模式清除未应用的建议，重新开始或停止后的不稳定采样不得沿用旧的可应用状态。采样期间固定参考、不自动改动正式游玩；应用保存、取消保留原值。游玩暂停仍只有原皮肤Retry/Quit。
- 设置页Autoplay、游玩倍速、语言三行分别在y=426、462、498，值控件统一112×32。倍速值点击输入，左右32×32步进按钮，通过共用Rect绘制和命中；Home恢复1.00×。倍率范围0.50–2.00、步进0.05，每局固定，非原速Mod不保存或比较原速成绩。游玩与结算显示本局倍率；输入Esc取消，不穿透菜单。

## 输入、语言与缩放

- 每次移动 / 缩放控件都追踪其 MouseDown、MouseMove、键盘焦点和录入状态。绘制和输入优先使用同一个 Rect；命中边界采用左上包含、右下不包含。
- 搜索栏悬停显示系统I形鼠标与轻微高亮，聚焦显示500ms周期明灭的插入光标，输入时重置为可见。复用主时钟；文字宽度只在查询/组合文本变化时测量，长输入横向偏移以保持末尾光标可见。系统光标资源延迟创建并缓存，仅悬停状态改变时切换，菜单/游玩/失焦恢复箭头，窗口关闭前释放。
- 语言标签中文为“语言”，英文为“Language”；通过 `tr` 切换。其他界面标签也不能混排两种语言，歌曲名称、作者及皮肤图片原文保持不变。
- 新设置必须兼容旧配置和无效输入，不能改写用户其他键位、帧率、音量或偏移；测试使用 finally 恢复原配置字节。
- 显示页增加游玩背景可见度（y=548），值控件112×32，左右32×32步进，点击数值输入0–100%，步进5%，Home恢复30%。数值越大背景越清晰，0%隐藏、100%原图；仅影响游玩及其暂停底图，选曲和结算保持各自配置。复用背景纹理，不重新解码或逐帧读写配置。
- 背景铺满原生窗口；轨道和前景等比适配。使用 `canvasPoint` / `handleWindowEvent` 映射指针，禁止单独拉伸音符或另设鼠标缩放公式。
- 暂停时禁止设置交互和游玩判定穿透；Esc 先取消按键录入 / 数值编辑，再按已有规则关闭菜单。
- 选曲期间图片解码、缩放及试听文件加载不能放回每帧同步路径；纹理创建仍归 SDL 主线程。图片和音频各最多一个在途加载任务，只提交当前需求，关闭窗口 / 音频设备前释放在途结果。
- 歌曲条缩略图与全屏背景分开缓存，保持容量和像素上限；失败加载须退避，不能逐帧重试。调整滚动层级时保持绘制顺序与命中顺序一致。

## 验收

1. 构建：`powershell -NoProfile -ExecutionPolicy Bypass -File tools/build.ps1`。
2. 逻辑回归：`./target/release/bin/main.exe --ui-check`，覆盖控件尺寸 / 对齐合同、点击区域、语言保存与兼容、缩放坐标、录入取消、暂停和结算操作。
3. 修改业务逻辑时执行对应已有检查；不要反复运行无关全量测试。
4. 不默认增加截图或审美测试。交付时报告实际改动与逻辑结果，视觉由用户验收。
