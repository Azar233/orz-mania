# UI 规范

本文件约束后续 UI 修改，目标是保持简洁、统一和可维护。尺寸均为 1280×720 逻辑画布单位；窗口缩放通过现有画布映射完成。

## 控件类别

同类控件保持相同尺寸和字体，不因中文或英文、ON/OFF 或当前选项而改变宽度。不同用途的类别允许使用表中不同尺寸。

| 类别 | 尺寸 | 字号 | 使用位置 |
| --- | --- | --- | --- |
| 设置值按钮 / 输入框 | 112×32 | 16 | 语言、自动演示、VSync、FPS 显示、自定义 FPS |
| 侧栏导航 / 关闭菜单 | 174×36 | 16 | Esc 菜单侧栏 |
| 页脚操作按钮 | 156×36 | 16 | 恢复默认、退出游戏、结算返回 / 重试 |
| 曲库导入操作 | 488×46 | 16 | 导入文件夹、导入谱面、刷新 |
| 暂停操作（皮肤例外） | 398×116 | 素材原字形 | Retry / Quit，使用 pause-retry.png / pause-back.png，暂停时只显示这两个操作 |
| 分段选择器 | 高 32 | 14 | FPS 预设、1K–9K；宽度随组内数量等分 |
| 按键绑定键帽 | 高 96，宽度按轨道数计算 | 主键名 18–28 | 保留现有长键名缩小和窄键帽缩写逻辑 |
| 标题栏菜单入口 | 116×36 | 16 | Esc 菜单 |

## 排版与状态

- 普通按钮用 `menuButton`；设置值用 `settingValueRect` / `settingValueButton`，右边缘统一为 x=980。不要另写语言按钮或开关的专属尺寸。
- 游玩暂停界面的 Retry / Quit 是用户明确指定的皮肤例外，沿用原有图片、字形与透明度反馈，不改成普通菜单按钮，也不因界面语言切换重绘素材文字。绘制与命中区域共用 `pauseActionRect`。
- 设置行标签用 `centeredSettingLabel`，与同一行的值控件垂直居中；值文本使用 `centeredText`，按实际字体度量计算位置。不要靠固定偏移猜测文字中心。
- 设置行标签字号 17，按钮 / 输入值字号 16，辅助说明 12–14；页面标题 26。长文案优先精简或调整换行，不能溢出相邻控件。
- 普通控件圆角为 4；底色 RGB(38,32,47)，选中 / 启用底色 RGB(72,42,65)，强调文字使用 `PINK`。不要把普通选项做成整块高亮粉色。
- 分段选择器采用相同选中底色与强调文字。键帽可加细边框表达焦点 / 录入，不能改变尺寸导致排列跳动。
- 页面内边缘、同一列的控件、同组按钮的间隔必须对齐。同一组使用固定步距，不为个别选项添加例外偏移。
- 头部和菜单使用项目品牌图标。游戏皮肤中的音符、判定和成绩图像遵循皮肤布局，不与普通表单按钮混为一类。
- 长条尾帽与条身使用同一圆角几何、颜色和透明度，避免完整圆形尾帽与独立半透明贴图叠加产生接缝。长条头覆盖条身下端；绘制修改不顺带改变尾部判定规则。
- 选曲左栏宽度与338宽的封面对齐，标题和作者不得溢出到右侧歌曲列表。键数与时长同列展示，不覆盖封面。超长标题才启用带两端停留的滚动；宽度只在文字改变时测量，复用已有时钟和字体缓存，不增加逐帧文字重建或独立计时线程。

## 输入、语言与缩放

- 每次移动 / 缩放控件都追踪其 MouseDown、MouseMove、键盘焦点和录入状态。绘制和输入优先使用同一个 Rect；命中边界采用左上包含、右下不包含。
- 语言标签中文为“语言”，英文为“Language”；通过 `tr` 切换。其他界面标签也不能混排两种语言，歌曲名称、作者及皮肤图片原文保持不变。
- 新设置必须兼容旧配置和无效输入，不能改写用户其他键位、帧率、音量或偏移；测试使用 finally 恢复原配置字节。
- 背景铺满原生窗口；轨道和前景等比适配。使用 `canvasPoint` / `handleWindowEvent` 映射指针，禁止单独拉伸音符或另设鼠标缩放公式。
- 暂停时禁止设置交互和游玩判定穿透；Esc 先取消按键录入 / 数值编辑，再按已有规则关闭菜单。
- 选曲期间图片解码、缩放及试听文件加载不能放回每帧同步路径；纹理创建仍归 SDL 主线程。图片和音频各最多一个在途加载任务，只提交当前需求，关闭窗口 / 音频设备前释放在途结果。
- 歌曲条缩略图与全屏背景分开缓存，保持容量和像素上限；失败加载须退避，不能逐帧重试。调整滚动层级时保持绘制顺序与命中顺序一致。

## 验收

1. 构建：`powershell -NoProfile -ExecutionPolicy Bypass -File tools/build.ps1`。
2. 逻辑回归：`./target/release/bin/main.exe --ui-check`，覆盖控件尺寸 / 对齐合同、点击区域、语言保存与兼容、缩放坐标、录入取消、暂停和结算操作。
3. 修改业务逻辑时执行对应已有检查；不要反复运行无关全量测试。
4. 不默认增加截图或审美测试。交付时报告实际改动与逻辑结果，视觉由用户验收。
